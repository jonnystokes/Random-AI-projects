# Designer Notes For HTML/PDF Export

Last updated: 2026-05-06

## Purpose

This file is for the later AI or tool that converts the manuscript into HTML and PDF.

Do not treat this file as manuscript content.

## Layer Labels

The manuscript may contain these single-word labels:

- `Simple`
- `Applied`
- `Professional`
- `Code`

The writing meaning of those labels lives in `writing_style_guide.md`. This file only controls future layout treatment.

## Label And Color Requirement

Each layer label should be visually distinct next to its block.

Only the label needs color treatment. Do not color the full text block.

Markdown cannot choose the final colors. Choose the label colors during HTML/PDF conversion and keep the color assignment stable throughout the finished book.

The manuscript should keep the labels as plain GitHub-flavored Markdown text. The converter should style those labels later.

## Suggested Structural Pattern

When all four labels appear in a topic, the usual visual order is:

1. `Simple`
2. `Applied`
3. `Professional`
4. `Code`

Do not assume every topic will contain every label.

## Forms Policy

Forms should never be displayed in the book.

Forms may be referenced, discussed, summarized, or described, but not shown as full blank forms.

## Source Policy For Added Content

Future design/export work should not add new technical content.

If factual content must be checked during a production pass, use the manuscript, the research files, and user-approved sources rather than inventing missing information.
