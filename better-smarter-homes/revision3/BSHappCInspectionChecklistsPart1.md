# Appendix C — Inspection Checklists

*Working checklists for every inspection from site evaluation through certificate of occupancy*

This appendix turns the inspection sequence described in the Legal, Permits, and Inspections chapter into actionable, fillable checklists that the owner-builder uses during the actual build. Each inspection has:

- **Pre-Inspection Self-Check** — what the owner-builder verifies before calling the inspector. Catching issues here saves a failed inspection (and the re-inspection fee, plus the schedule delay).
- **Documentation Required** — what to have ready for the inspector
- **Inspector's Likely Checklist** — what the inspector is going to look at, drawn from code and common practice
- **Common Failure Points** — issues that frequently cause re-inspections
- **Sign-Off Section** — to be completed when the inspection passes

These checklists are designed to be **printed and used in the field** — checked off in pen, marked up with notes, signed by the inspector, then filed in the project binder described in the Documentation, Maintenance, and Future Upgrades chapter.

The inspection sequence follows the typical order a build progresses through, but specifics vary by jurisdiction. Always verify with the local building department which inspections are required for the specific project.

---

## How to Use These Checklists

**1. Print or copy each relevant checklist before starting work in that phase.**

**2. Work through the Pre-Inspection Self-Check carefully** — every item, in person, with the actual installation in front of you. Don't take shortcuts; the inspector won't.

**3. Schedule the inspection only after the self-check passes** — typically 24–48 hours of advance notice required, sometimes more in busy seasons or rural areas.

**4. Have all documentation organized and ready** — permit, approved plans, prior inspection sign-offs, manufacturer specs for any unusual products.

**5. During the inspection: be present, take notes, ask questions.** The inspector's job is to verify code compliance, but they're also a knowledgeable professional with experience that can be invaluable. A respectful, prepared owner-builder gets far more out of the relationship than one who treats the inspector as an obstacle.

**6. After the inspection, file the signed checklist immediately** in the project binder. Never lose this paperwork — at resale (3+ years later), the buyer's inspector and lender will appreciate complete records.

## Part 1 — Site Preparation Inspections

## Inspection #1 — Septic Site Evaluation

**Authority:** County Environmental Health or Oregon DEQ (varies by county)

**When:** Before purchase if possible (as a contingency); definitely before any building permit application.

**What it determines:** Whether the site can support a conventional or alternative septic system, and the system's required design.

### Pre-Inspection Self-Check

```
[ ] Property corners marked or known
[ ] Proposed building location flagged
[ ] Access for installer's truck verified
[ ] Trees/brush in test pit area cleared
[ ] Test pit locations identified (typically 3+ test pits)
[ ] No standing water in test pit areas (test in dry weather)
[ ] Owner or representative will be on-site
[ ] Permit application submitted with fee
[ ] Site plan with proposed structure location available
```

### Documentation Required

```
[ ] Site permit application
[ ] Site plan showing:
    [ ] Property boundaries
    [ ] Proposed building footprint
    [ ] Proposed septic field location
    [ ] Proposed well location (10+ ft from septic field min, 100+ ft preferred)
    [ ] Surface drainage / slope direction
    [ ] Any existing structures
[ ] Property tax map / parcel data
[ ] Owner contact information
```

### Inspector's Likely Checklist

```
[ ] Soil test pits dug to 6+ feet depth
[ ] Soil color, texture, and structure documented (each layer)
[ ] Depth to seasonal high water table observed
[ ] Depth to bedrock observed
[ ] Percolation test performed at design depth
[ ] Slope of natural ground measured
[ ] Setback from property lines verified (10 ft typical from boundaries)
[ ] Setback from well location verified (100 ft preferred, 50 ft minimum to a well)
[ ] Setback from surface water verified (50–100 ft typical)
[ ] Approval recommendation issued OR
[ ] Conditional approval (alternative system required)
[ ] Denial (site not suitable — rare)
```

### Common Failure Points

- **Water table too high** — fails for conventional drain fields
- **Bedrock too shallow** — limits trench depth
- **Slope too steep** — requires alternative system
- **Setbacks not achievable** — small lots may fail
- **Soil too tight (clay)** — fails percolation, requires sand mound or alternative

### Documentation Output

The inspector issues a **Site Evaluation Report** specifying:
- Approved system type (conventional, sand filter, ATU, etc.)
- Design flow rate
- Field size and depth
- Required soil or alternative materials

## Inspection #2 — Well Inspection

**Authority:** Oregon Water Resources Department (well log filed; physical inspection by licensed driller; well water quality test by certified lab)

**When:** Drilled before building permit; water quality test before occupancy.

### Pre-Inspection Self-Check (post-drill)

```
[ ] Well log received from licensed driller
[ ] Wellhead protected (sanitary cap, locking option)
[ ] Casing extends at least 12 inches above grade
[ ] Concrete pad poured around casing (some jurisdictions)
[ ] Surface drainage flows away from wellhead
[ ] Pump installed at correct depth per driller
[ ] Pressure tank installed at well or in basement
[ ] Electrical connection per code (sealed conduit, GFCI)
[ ] No surface contamination sources within 50 ft (preferably 100 ft)
[ ] Water sample collected for lab testing in proper sterile container
```

### Documentation Required

```
[ ] Well permit (issued before drilling)
[ ] Driller's report / well log including:
    [ ] Total depth
    [ ] Static water level
    [ ] Pumping water level
    [ ] Yield (GPM at 4-hour pump test)
    [ ] Casing material, depth, and diameter
    [ ] Grouting / sealing depth
    [ ] Driller's license number
[ ] Pump installation record
[ ] Water quality lab report
```

### Required Water Quality Tests (Oregon recommendations)

```
[ ] Bacteria (Total Coliform and E. coli)        Result: ____________
[ ] Nitrate (NO3-N)                              Result: ____________ mg/L
[ ] Arsenic                                      Result: ____________ μg/L
[ ] pH                                           Result: ____________
[ ] Total dissolved solids (TDS)                 Result: ____________ mg/L
[ ] Hardness                                     Result: ____________ mg/L as CaCO3
[ ] Iron                                         Result: ____________ mg/L
[ ] Manganese                                    Result: ____________ mg/L

Optional but recommended:
[ ] Lead                                         Result: ____________ μg/L
[ ] Radon (in water)                             Result: ____________ pCi/L
[ ] Fluoride                                     Result: ____________ mg/L
[ ] Sulfate                                      Result: ____________ mg/L

```

### Common Failure Points

- **Insufficient yield** — under 5 GPM may not support a household; 10+ GPM recommended for this design
- **Bacteria contamination** — surface water intrusion or improper sealing
- **High nitrate** — agricultural impact or septic too close
- **High arsenic** — natural in some Oregon areas; treatable but expensive
- **Improper grouting** — driller error; can require redrilling

## Inspection #3 — Driveway / Access Permit and Inspection

**Authority:** County Roads Department or ODOT (if accessing a state highway)

**When:** Before substantial construction begins; many jurisdictions require approved access before issuing a building permit.

### Pre-Inspection Self-Check

```
[ ] Driveway permit application submitted
[ ] Driveway location surveyed and marked
[ ] Sight distance from access point verified (clear visibility both directions)
[ ] No drainage structures in approach path (or culverts planned)
[ ] Access point doesn't interfere with road drainage
[ ] Width meets jurisdiction minimums (typically 12 ft minimum, 16 ft preferred)
[ ] Approach radius adequate for fire truck (Oregon fire code requirement)
[ ] If long driveway, turnaround for fire truck planned
[ ] Maximum grade does not exceed 10% (fire code)
[ ] Cul-de-sac or hammerhead at end of long driveway if required
```

### Documentation Required

```
[ ] Driveway permit (issued by jurisdiction)
[ ] Site plan showing driveway alignment
[ ] If on a state highway: ODOT access permit
[ ] Culvert specifications if culvert needed
[ ] Address assigned by county (911 address)
[ ] Address sign installed at the access point
```

### Inspector's Likely Checklist

```
[ ] Driveway location matches permit drawing
[ ] Width per code
[ ] Sight distance adequate
[ ] Drainage handled (culvert sized correctly if needed)
[ ] Surface adequate for fire truck (gravel or paved, all-weather)
[ ] Grade meets requirements
[ ] Address sign visible from road
[ ] Turnaround per code if driveway over 150 ft
[ ] Hammerhead or cul-de-sac if required
```

### Common Failure Points

- **Inadequate sight distance** — vegetation removal may be required
- **Improper culvert** — undersized or wrongly placed
- **Excessive grade** — re-cut may be required
- **Missing turnaround** — long driveways must accommodate fire truck

## Inspection #4 — Erosion and Sediment Control

**Authority:** County or DEQ (varies by jurisdiction; required for sites disturbing more than 1 acre, or smaller sites near sensitive water bodies)

**When:** Before substantial earthwork begins.

### Pre-Inspection Self-Check

```
[ ] ESCP (Erosion and Sediment Control Plan) prepared and submitted
[ ] Silt fence installed at all downhill perimeters of disturbed area
[ ] Silt fence trenched in (not just laid on surface)
[ ] Silt fence stakes spaced no more than 6 ft apart
[ ] Stabilized construction entrance installed (gravel pad)
[ ] Inlet protection on any drainage structures
[ ] Stockpiles covered or seeded if more than temporary
[ ] Drainage from disturbed areas directed to sediment trap or basin
[ ] Concrete washout area designated and contained
[ ] Daily inspection log started
```

### Documentation Required

```
[ ] ESCP approved by jurisdiction
[ ] Daily inspection log with weather conditions
[ ] Maintenance log
```

### Inspector's Likely Checklist

```
[ ] Silt fence properly installed (trenched, spaced)
[ ] Drainage controls in place
[ ] Vehicle tracking minimized (gravel construction entrance)
[ ] Stockpiles managed
[ ] Concrete washout properly contained
[ ] Daily inspections being logged
[ ] No visible sediment leaving the site
[ ] Stabilization of disturbed areas progressing as work allows
```

### Common Failure Points

- **Silt fence laid on surface, not trenched** — fails as soon as it rains
- **Inadequate construction entrance** — mud tracked to public road
- **Concrete washout in soil** — discharge violation
- **Stockpiles uncovered** during rain
- **Daily inspection log not maintained**

## Part 2 — Foundation Inspections

## Inspection #5 — Pre-Footing / Excavation Inspection

**Authority:** Building Department

**When:** After excavation is complete, before any concrete is placed.

### Pre-Inspection Self-Check

```
[ ] Excavation matches approved plans (location, dimensions, depth)
[ ] Bottom of excavation reaches design depth
[ ] Excavation extends below frost line (12-36 inches in Oregon)
[ ] Bearing soil inspected (undisturbed, no organic material, no soft areas)
[ ] Sub-grade compacted if engineered fill was specified
[ ] Excavation walls stable (sloped or shored if over 4 ft deep)
[ ] No standing water in excavation
[ ] Drainage path planned (water won't pool here)
[ ] Survey staking still in place / verified
[ ] Form work for footings (if separate from mat) ready or in place
[ ] Sleeves for utility penetrations roughly positioned
[ ] Site safe for inspector to enter (ramps, ladders as needed)
```

### Documentation Required

```
[ ] Building permit
[ ] Approved plans
[ ] Soils report (if applicable to site)
[ ] Survey stakes / lines
```

### Inspector's Likely Checklist

```
[ ] Excavation matches plans
[ ] Bottom on undisturbed native soil OR properly compacted engineered fill
[ ] Bottom level (or stepped per design)
[ ] Below frost depth
[ ] No water, no soft spots
[ ] Setbacks from property lines verified
[ ] Footing dimensions match plan (if separate footing exists)
[ ] Frost-protection details for any below-grade-but-above-foundation portions
```

### Common Failure Points

- **Excavation too shallow** — must dig deeper
- **Soft / disturbed subgrade** — must be compacted or removed
- **Standing water** — must be drained before pouring
- **Wrong location** — survey error; must re-stake
- **Footing dimensions wrong** — common when transitioning from plan to field

## Inspection #6 — Foundation Reinforcement / Pre-Pour Inspection

**Authority:** Building Department (sometimes structural engineer of record also signs off)

**When:** After all rebar is placed and tied, sub-slab insulation and vapor barrier installed, utility sleeves placed; before concrete is poured.

### Pre-Inspection Self-Check

```
SUB-GRADE PREPARATION:
[ ] Compacted gravel base placed and leveled (4-12 inches)
[ ] Capillary break layer (1+ inch crushed rock with no fines, 4 inches)
[ ] Vapor barrier (10-15 mil polyethylene) continuous, lapped 6+ inches at seams
[ ] Vapor barrier sealed at penetrations and at edges (returning up the form)
[ ] Under-slab insulation installed (Type XIV EPS, 4 inches in two staggered layers)
[ ] Insulation tight to all surfaces, no gaps
[ ] Second vapor barrier above insulation (optional but recommended)

REBAR:
[ ] Rebar grid spacing matches plan (typically 12 in OC both ways)
[ ] Rebar size matches plan (#4, #5 per design)
[ ] Bars supported on chairs at correct height (typical 2-3 inches above the bottom)
[ ] All laps minimum 40 bar diameters
[ ] All laps tied (rebar tying wire, every other intersection minimum)
[ ] Vertical dowels for walls bent up at correct locations
[ ] Vertical dowels at correct height for wall splicing
[ ] Additional reinforcement at corners and openings per plan
[ ] Rebar not touching the vapor barrier (chairs working)
[ ] Rebar not touching forms (form ties or chairs at edges)
[ ] No rust/scale beyond surface bloom
[ ] Continuous bond beam reinforcement at perimeter

UTILITIES AND PENETRATIONS:
[ ] Electrical service conduit sleeve placed
[ ] Water service conduit sleeve placed
[ ] Sewer line sleeve placed (for waste outflow at ground level)
[ ] Radon vent piping under-slab installed (capped above slab)
[ ] Any other utility sleeves placed
[ ] Sleeves sealed where they pass through vapor barrier

CEE GROUNDING ELECTRODE:
[ ] At least one #4 rebar bent up to extend 6+ inches above slab for grounding electrode
[ ] CEE rebar position marked on plan (NEC 250.52(A)(3) — 20 ft minimum length)
[ ] Bonding clamp ready for grounding electrode conductor

FINAL CHECKS:
[ ] No debris, no leaves, no trash in forms
[ ] Rebar dry (light surface rust OK; flaking rust must be cleaned)
[ ] Forms square, plumb, braced
[ ] Concrete delivery scheduled
[ ] Concrete placement crew arranged
[ ] Pumper truck if needed
[ ] Weather forecast acceptable (no rain in next 24 hours, temperature 40-90°F preferred)
[ ] Owner and crew know plan for placement, finishing, and curing
```

### Documentation Required

```
[ ] Building permit
[ ] Approved plans (with engineer's stamp on structural sheets)
[ ] Engineer's review of rebar (if required by jurisdiction)
[ ] Concrete mix design (delivered with the load)
[ ] Previous inspection sign-offs (#5 pre-footing)
```

### Inspector's Likely Checklist

```
[ ] Excavation properly prepared
[ ] Vapor barrier and insulation correctly placed
[ ] Rebar grid spacing per plan
[ ] Rebar size per plan
[ ] Rebar tied at intersections
[ ] Rebar laps adequate
[ ] Rebar cover (top, bottom, sides) per plan and code
[ ] Vertical dowels at wall locations
[ ] Reinforcement at corners and openings
[ ] CEE provisions in place
[ ] Sleeves placed for all utilities
[ ] No uncovered rebar that will be exposed (corrosion concern)
[ ] Forms straight, plumb, secured
[ ] Engineer's signature/stamp on plan if required
```

### Common Failure Points

- **Rebar size wrong** — caught by inspector reading plans
- **Rebar spacing too wide** — common error
- **Rebar laps too short** — can be hard to verify; measure carefully
- **Insufficient cover** — bars too close to forms or surfaces
- **Vapor barrier torn or missing** — caught by inspector
- **CEE not provisioned** — easy to forget; required for electrical
- **Sleeves missing** — drilling through cured concrete is expensive

## Inspection #8 — Foundation Damp-Proofing / Waterproofing

**Authority:** Building Department

**When:** After concrete is fully cured (typically 7+ days, ideally 28 days for full strength), before backfill.

### Pre-Inspection Self-Check

```
[ ] Concrete surface clean (no laitance, oil, dirt)
[ ] Surface profile per membrane manufacturer (smooth or roughened)
[ ] All form ties cut flush and patched
[ ] Honeycomb voids patched
[ ] Cracks repaired (caulked or routed and grouted)
[ ] Membrane primer applied per manufacturer (if required)
[ ] Waterproofing membrane installed:
    [ ] Liquid-applied: continuous, full thickness, no thin spots, fully cured
    [ ] OR sheet membrane: continuous, lapped per manufacturer (typically 3 in min)
    [ ] All seams sealed
    [ ] Inside corners reinforced
    [ ] Outside corners detailed
[ ] Membrane extends from footing top to grade level (or 6 in above grade)
[ ] Membrane terminates with proper edge detail
[ ] Sleeves and penetrations flashed/sealed
[ ] Protection board installed (if specified)
[ ] No bare areas of concrete in contact with soil
```

### Documentation Required

```
[ ] Membrane manufacturer's product data
[ ] Application method documentation (spray, trowel, etc.)
[ ] Photos of membrane application
[ ] Previous foundation pour inspection sign-offs
```

### Inspector's Likely Checklist

```
[ ] Membrane visible and continuous
[ ] No bare concrete below grade
[ ] Penetrations sealed
[ ] Termination at grade is clean
[ ] No damaged or punctured areas
[ ] Protection board (if specified) installed
[ ] If hydrostatic conditions: waterproofing rated, not damp-proofing
```

### Common Failure Points

- **Thin spots in liquid-applied membrane** — particularly at corners
- **Penetrations not sealed** — sleeves, anchors, conduit
- **Membrane damaged before backfill** — torn, punctured, scraped
- **Cold-joint at footing/wall not detailed**

## Inspection #9 — Foundation Drainage / Pre-Backfill

**Authority:** Building Department

**When:** After waterproofing membrane is in place, drainage system installed, before backfill.

### Pre-Inspection Self-Check

```
PERIMETER DRAIN:
[ ] 4-inch perforated drainpipe at base of foundation (perforations down)
[ ] Drainpipe slopes at least 1/4 in per foot toward daylight or sump
[ ] Daylight outlet protected with rodent guard
[ ] Or sump pit constructed if no daylight available
[ ] Filter fabric wraps the drainpipe and gravel envelope completely

DRAINAGE GRAVEL:
[ ] Clean crushed stone (1.5+ inch, no fines) covering drainpipe
[ ] Gravel envelope at least 12 inches all around drainpipe
[ ] Gravel rises at least 6 inches above drainpipe along the wall
[ ] No mixing with native soil (filter fabric prevents this)

DRAINAGE MAT (if specified):
[ ] Dimpled drainage mat installed against waterproofing membrane
[ ] Drainage mat extends from footing top to grade
[ ] Drainage mat terminates with edge protection at top
[ ] Vertical channels in drainage mat oriented correctly (water flows down)
[ ] Mat connected to perimeter drain at the bottom

FILTER FABRIC:
[ ] Filter fabric covers the gravel before native soil backfill
[ ] Fabric extends up the drainage mat or wall

FINAL CHECKS:
[ ] Backfill material identified (clean fill, not the dug spoils with rocks/clay)
[ ] Compaction equipment ready (plate compactor)
[ ] Layer-by-layer backfill plan (8-12 inch lifts, compacted)
```

### Documentation Required

```
[ ] Previous waterproofing inspection sign-off
[ ] Daylighting permit if outletting to surface drainage
[ ] Photos of drainage installation before covering
```

### Inspector's Likely Checklist

```
[ ] Perimeter drain visible (or just covered)
[ ] Drain slope acceptable
[ ] Outlet daylighted or pumped
[ ] Drainage gravel envelope adequate
[ ] Filter fabric in place
[ ] Drainage mat installed if specified
[ ] No bare soil against foundation
[ ] Daylight outlet not blocked
[ ] Sump pit (if used) properly built
```

### Common Failure Points

- **Drainpipe slope flat or backward** — causes ponding instead of drainage
- **Outlet blocked** — must drain to daylight or pump
- **Filter fabric missing** — gravel will fill with soil over time
- **Native soil used as backfill near drain** — defeats the purpose
- **Drainage mat installed inverted** — channels can't carry water down

## Inspection #10 — Under-Slab / Pre-Slab Pour Inspection

**Authority:** Building Department

**When:** When the basement floor or other slab-on-grade is ready to pour, after sub-slab insulation, vapor barrier, and rebar are placed; before concrete.

This inspection is similar to Inspection #6 but specifically for an interior slab (basement floor). For the mat foundation, it's combined with #6.

### Pre-Inspection Self-Check

```
SUBGRADE:
[ ] Compacted base course (4+ inches of crushed rock)
[ ] Smooth and level

CAPILLARY BREAK:
[ ] 4 inches of clean 1+ inch crushed rock with no fines

UNDER-SLAB INSULATION:
[ ] Type XIV EPS, 4 inches in two staggered 2-inch layers
[ ] Tight to all walls and forms
[ ] No gaps between sheets

VAPOR BARRIER:
[ ] 10-15 mil polyethylene, fully covering insulation
[ ] Lapped 6+ inches at seams, taped
[ ] Sealed at penetrations
[ ] Up the wall 6+ inches and behind any future furring

RADON VENT:
[ ] 4-inch perforated pipe under slab in gravel layer
[ ] Pipe rises through slab and capped above (to be vented later)

REBAR / WIRE MESH:
[ ] 6x6-W2.0 welded wire reinforcement OR rebar grid per plan
[ ] On chairs at correct height (mid-slab typically)
[ ] Continuous

FINAL:
[ ] Sleeves for any in-slab plumbing (typically minimal in this design — see the Plumbing Systems chapter)
[ ] Embedded conduit (typically minimal in this design — see the Electrical Power and Lighting chapter)
[ ] Pour scheduled, weather acceptable
```

### Sign-Off

