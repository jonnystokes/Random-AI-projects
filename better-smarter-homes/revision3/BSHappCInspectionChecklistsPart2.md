## Part 3 — Wall and Structural Inspections

## Inspection #11 — Masonry Reinforcement / Pre-Grout Inspection

**Authority:** Building Department (sometimes also requires structural engineer of record)

**When:** Before the cores of CMU walls are filled with grout. Typically inspected in lifts (every 4-8 feet of wall height).

### Pre-Inspection Self-Check

```
WALL CONSTRUCTION:
[ ] CMU laid plumb (vertical) — checked with a level on every fourth course minimum
[ ] CMU laid level (horizontal) — bed joints uniform
[ ] Mortar joints struck consistently (concave, V-joint, or as specified)
[ ] Joint thickness 3/8 in nominal (uniform, no joint less than 1/4 in or more than 1/2 in)
[ ] All cells aligned vertically (clean stack so vertical rebar can pass through)
[ ] No mortar droppings in cells to be grouted
[ ] Cleanout openings at the bottom of walls (one per cell to be grouted, removed before grouting)
[ ] No visible damage to block (cracks, chips beyond manufacturer tolerance)

VERTICAL REBAR:
[ ] Vertical bars in cores per plan (size, spacing — typically every 16-32 in OC for residential)
[ ] Bars extend the full height being grouted
[ ] Bars tied to dowels from foundation (laps minimum 40 bar diameters)
[ ] Bars centered in cells (not touching block walls)
[ ] Bar position visible through cleanouts

HORIZONTAL REBAR:
[ ] Horizontal bond beam reinforcement in bond beam blocks per plan
[ ] Bond beams typically every 4 courses or as specified
[ ] Top course bond beam continuous around perimeter
[ ] Horizontal joints reinforcement (ladder or truss type) in non-bond-beam courses
[ ] Bars tied at intersections

CAVITY WALL (if applicable):
[ ] Inner wythe at correct height (matched to outer or staged appropriately)
[ ] Cavity insulation installed in two staggered 2-inch layers (4-inch cavity)
[ ] FRP wall ties at specified spacing (16 in OC vertical, 24 in OC horizontal)
[ ] FRP ties properly embedded in mortar joints of both wythes
[ ] No mortar bridging the cavity (defeats the thermal break)
[ ] Weep holes at base of veneer wythe (every 24 in OC at the bottom course)
[ ] Through-wall flashing at the base of the cavity

OPENINGS:
[ ] Lintels in place per plan
[ ] Lintel bearing minimum 8 in on each side
[ ] Reinforcement at jamb edges of openings (extra vertical bars)
[ ] No mortar bridging at frames
[ ] Window and door rough-openings squared and within tolerance

CLEANOUTS:
[ ] Cleanout openings at the bottom of every cell to be grouted (typically 4x6 in)
[ ] All loose mortar and debris removed from cells via cleanouts
[ ] Cleanouts ready to be sealed before grout placement (mortared shut at the right time)

ANCHOR BOLTS / EMBEDS:
[ ] All anchor bolts placed per plan
[ ] Anchor bolt size and embedment per plan
[ ] Holdowns / straps placed where required for seismic
```

### Documentation Required

```
[ ] Approved structural plans
[ ] Engineer's specification for grout (if applicable)
[ ] Mortar test results (if applicable)
[ ] Block manufacturer's certification (ASTM C90)
[ ] Photos of rebar before grouting
```

### Inspector's Likely Checklist

```
[ ] Wall plumb and level
[ ] Block laid in pattern per plan (running bond, etc.)
[ ] Vertical rebar size and spacing per plan
[ ] Vertical rebar laps adequate
[ ] Horizontal reinforcement per plan
[ ] Bond beams in correct courses
[ ] Wall ties at correct spacing (FRP — verify type with manufacturer documentation)
[ ] Cavity insulation in place and continuous
[ ] No mortar bridging insulation
[ ] Weep holes present at veneer base
[ ] Cleanouts adequate
[ ] Anchor bolts and embeds in correct positions
[ ] Lintel bearing adequate
[ ] No visible damage to wall
```

### Common Failure Points

- **Vertical bars not aligned with cores** — block must be re-laid
- **Bars touching block walls** — corrosion concern
- **Mortar bridging cavity** — thermal break compromised
- **Wall ties spaced wrong** — easy mistake; recount
- **Weep holes missing** — must add before grouting
- **Cleanouts inadequate** — debris will be trapped

## Inspection #13 — Floor Slab / Service Layer Pre-Pour

**Authority:** Building Department

**When:** When the elevated floor slab is ready to pour. Service layer construction (joists, deck, MEP infrastructure) is in place; rebar and forming are complete.

### Pre-Inspection Self-Check

```
SERVICE LAYER STRUCTURE:
[ ] Steel joists (or precast joists) installed per plan
[ ] Joists set on bearing courses with proper end clearance
[ ] Joist hangers / connections per plan
[ ] All joists level and aligned
[ ] Spacing per plan (typically 4-6 ft OC for open-web steel joists)
[ ] Joists secured against rotation
[ ] No damaged joists (bent, dented, or rust beyond bloom)

DECK:
[ ] Steel decking placed and fastened (composite or non-composite per design)
[ ] Decking oriented per design (ribs running correct direction)
[ ] Side laps fastened per manufacturer (typically every 12 in)
[ ] End laps over joists (with required overlap)
[ ] No buckles, dents, or damage
[ ] Edge forms in place around perimeter
[ ] Pour stops at openings and edges

EMBEDDED ITEMS:
[ ] Service layer infrastructure in place below the deck (visible from above before pour):
    [ ] Plumbing trunk lines
    [ ] Electrical conduit trunk lines
    [ ] HVAC ducts (rigid metal)
    [ ] Hydronic primary loops
[ ] All embedded items SECURED so they don't move during the pour
[ ] All embedded items inspected to be certain none are damaged or kinked

REBAR:
[ ] Rebar per plan (top and bottom mats for typical structural slab)
[ ] Tied at intersections
[ ] Cover correct top and bottom
[ ] Chairs / supports holding rebar at correct height
[ ] Reinforcement at openings and edges per plan

FIBER REINFORCEMENT:
[ ] Fiber type and dose specified to concrete supplier (steel + poly per the Structural Design chapter)
[ ] Note: fibers added at the plant, not on site

EDGES AND OPENINGS:
[ ] All openings blocked out (stairs, mechanical chases, future skylights)
[ ] Edge forms square, plumb, and braced
[ ] Pour stops at section breaks (if pouring in multiple sections)
[ ] Anchor bolts for next floor walls placed per plan
[ ] Vertical dowels for next floor walls bent up at correct positions

FINAL:
[ ] No debris on deck
[ ] Concrete supplier confirmed
[ ] Pumper truck confirmed
[ ] Crew arranged
[ ] Curing materials ready
```

## Inspection #16 — Plumbing Rough-In

**Authority:** Plumbing Inspector

**When:** All in-wall and in-service-layer plumbing installed, BEFORE drywall or finishes cover anything.

### Pre-Inspection Self-Check

```
DRAIN, WASTE, VENT (DWV):

[ ] All drains and vents installed per plan
[ ] Pipe size per fixture units (per OPSC)
[ ] Pipe slope: 1/4 in per foot for 3 in and smaller, 1/8 in per foot for 4 in
[ ] All fittings DWV-grade (sanitary tees, long-sweep ells)
[ ] No flat fittings on vertical-to-horizontal transitions (no sanitary tees on side, only wye + 1/8 bend)
[ ] Cleanouts at:
    [ ] Base of every vertical stack
    [ ] Every change of direction more than 45°
    [ ] Maximum every 100 ft of horizontal run
    [ ] Building drain (within 5 ft of exit)
[ ] All fixtures stubbed out at correct rough-in heights:
    [ ] Toilet flange: 12.5 in to 13.5 in from finish wall
    [ ] Toilet supply: 6 in left of center, 6 in above floor
    [ ] Lavatory drain: 18 in AFF (varies by sink)
    [ ] Lavatory supply: 22 in AFF, 8 in apart (varies)
    [ ] Tub/shower drain: per fixture rough-in dimensions
    [ ] Shower valve: 48 in AFF center (varies)

VENTING (this design — individual vents per fixture, no AAVs):

[ ] Every fixture has an individual vent
[ ] Vents extend up through roof per plan or sidewall vent
[ ] Vents 1.5 in minimum diameter (some larger)
[ ] Vents tied together properly above the fixture flood rim
[ ] No vents within 10 ft horizontal of openings (or 3 ft above)
[ ] All vent connections accessible

WATER SUPPLY:

[ ] Main water trunk per plan (2-inch copper Type L per the Plumbing Systems chapter)
[ ] Hot and cold supply lines run to each fixture
[ ] PEX-A used for branch runs to fixtures (with EVOH oxygen barrier for radiant tie-in)
[ ] Hot water recirculation loop per plan
[ ] Pipe insulation on hot water lines (R-3 minimum, per energy code)
[ ] Pressure regulator (PRV) installed if incoming pressure > 80 psi
[ ] Isolation valves at major branches and at every fixture
[ ] Stub-outs at correct heights and offsets
[ ] All connections properly made (soldered, pressed, or expansion fittings as appropriate)
[ ] No CPVC (per design)
[ ] No galvanized (per design)

WATER HEATER:

[ ] Heat pump water heater installed per design
[ ] T&P relief valve installed
[ ] T&P discharge pipe to indirect waste receptor or to outside
[ ] Drain pan installed (where leaking would damage structure)
[ ] Expansion tank installed (closed system requires)
[ ] Seismic strapping (Oregon SDC D requires)
[ ] Power and condensate connections (verified by electrician for power)

PRESSURE TEST:

[ ] System filled with water
[ ] Pressurized to 100 psi
[ ] Held 24 hours minimum
[ ] No drop in pressure
[ ] All joints inspected dry

FIXTURE PROVISIONS:

[ ] All required fixture rough-ins per plan
[ ] Outdoor hose bibs installed (frost-proof if exposed)
[ ] Outdoor utility service bay rough-in per the Plumbing Systems chapter
[ ] Future fixture stub-outs (if any) capped and labeled

LABELING:

[ ] Major lines labeled in service layer
[ ] Shut-off valves accessible and labeled
```

### Documentation Required

```
[ ] Approved plumbing plan
[ ] Building permit
[ ] Pressure test record
[ ] Manufacturer's installation instructions for water heater
[ ] PEX manufacturer documentation (especially for PEX-A expansion fittings)
```

### Inspector's Likely Checklist

```
[ ] Pipe size per fixture units
[ ] Slope on drains correct
[ ] Cleanouts placed correctly
[ ] Vents per fixture (this design)
[ ] No improper fittings
[ ] Pressure test passing
[ ] Water heater installation correct
[ ] Backflow protection at irrigation, hose bibs, washing machine box
[ ] Trap seals in place (no dry traps)
```

### Common Failure Points

- **Drain slope reversed or flat** — common error
- **Improper fittings** — sanitary tees on horizontal-to-vertical transitions (must be wye + 1/8 bend)
- **Missing vents** — easy to forget on island sinks; this design uses individual vents which prevents this
- **Pressure test fails** — find the leak, fix, retest
- **Wrong fittings on PEX** — crimp on PEX-A loses self-healing; expansion preferred

## Inspection #17 — Plumbing Pressure Test (often part of #16)

This is included as a sub-step of the plumbing rough-in inspection. The water supply system is filled and pressurized, and the inspector verifies no pressure loss over the test period. The drain system is also pressure-tested with air or water-fill, depending on the configuration.

**Standard pressure test:**
- Water supply: 100 psi for 24 hours; no drop allowed
- Drainage: water-fill to top of system, or air at 5 psi for 15 minutes

The owner-builder performs the test before the inspector arrives. The inspector typically verifies the system is under pressure and asks for the test results to be documented.

## Inspection #18 — Electrical Rough-In

**Authority:** Electrical Inspector (state-licensed inspectors in Oregon)

**When:** All in-wall and in-service-layer electrical work installed, BEFORE drywall covers anything.

### Pre-Inspection Self-Check

```
SERVICE ENTRANCE:

[ ] Service entrance conductors installed from utility connection point to interconnect box
[ ] Meter base installed with utility-readable position

MAIN PANEL:

[ ] Main panel mounted on wall per code (height, working clearance)
[ ] 36 in working clearance in front
[ ] Main breaker installed at top
[ ] Bonding bushings on metallic conduit
[ ] Main bonding jumper between neutral and ground busses (only at main panel)
[ ] Branch breakers per plan
[ ] AFCI/GFCI breakers in correct circuits
[ ] Spare slots reserved per design (solar, EV, expansion)
[ ] Panel directory in place (or being completed)

SUBPANELS:

[ ] Subpanels installed per plan (one per floor or per area)
[ ] Subpanel feeders sized per plan
[ ] Subpanel main breaker (or no breaker if directly fed)
[ ] Neutral and ground busses SEPARATED at subpanels (no bonding jumper)
[ ] Bonding strap between subpanel ground bus and panel can
[ ] Branch breakers per plan
[ ] Working clearance per code

CONDUIT AND RACEWAYS:

[ ] EMT or PVC per design throughout
[ ] All conduit secured to structure per code
[ ] No more than 360° of cumulative bends between pull points
[ ] Pull boxes at correct intervals
[ ] Expansion fittings where conduit crosses building joints
[ ] Bushings on conduit ends in boxes
[ ] Conduit terminations at devices (couplings, connectors)
[ ] No exposed wire (everything in conduit, raceway, or NM-B-rated cable)

WIRING:

[ ] Wire size per breaker rating per NEC table
[ ] Wire color code (white = neutral, green = ground, black/red/blue = phases)
[ ] All conductors continuous (no buried splices outside boxes)
[ ] Ground conductor in every circuit (even when not strictly required)
[ ] Voltage drop OK (≤ 3% on long branches)
[ ] Splices in boxes only, with wire nuts or push-in connectors

OUTLETS AND SWITCHES:

[ ] Box at every required location (rough-in only — devices not yet installed)
[ ] Receptacle boxes at correct heights
[ ] Switch boxes at correct heights
[ ] Box fill calculated correctly (not overfilled for the wire count)
[ ] Pigtails/wires extending into box per code (6-8 inches)
[ ] Wires labeled or otherwise identifiable

AFCI/GFCI/SPECIAL:

[ ] AFCI on circuits per NEC 210.12 (essentially all habitable rooms)
[ ] GFCI on circuits per NEC 210.8 (wet areas)
[ ] Combination AFCI/GFCI specified for circuits requiring both
[ ] Whole-house surge protector (Type 2 SPD) at main panel

GROUNDING:

[ ] CEE grounding electrode connected (foundation rebar stub)
[ ] All metal water pipe bonded
[ ] Gas pipe bonded (if any)
[ ] Structural steel bonded (if any)
[ ] Equipment grounding conductors continuous

SPECIAL CIRCUITS:

[ ] EV charger conduit installed (capped, no wire pulled until installed)
[ ] Solar conduit installed (capped)
[ ] Smoke/CO detector circuit (not AFCI/GFCI protected)
[ ] HVAC equipment circuits per plan

LOW-VOLTAGE:

[ ] Cat6A drops to all required locations
[ ] Coax to entertainment locations
[ ] Network closet rough-in complete
[ ] Camera locations roughed in (PoE Cat6A)
[ ] Doorbell wiring
[ ] All low-voltage in separate conduit from line voltage

LABELING:

[ ] All conduit labeled at pull points
[ ] All cables labeled at terminations
[ ] Panel directories complete
```

```
HEAT PUMP / GROUND-SOURCE EQUIPMENT:

[ ] Refrigerant lines installed (typically by HVAC contractor — EPA 608 cert required)

[ ] Pull strings or pull boxes for any concealed duct routing

REGISTERS AND BOOTS:

[ ] Register boots installed at every supply and return location
[ ] Boots properly sized for the room and duct
[ ] Boots well-sealed to ductwork
[ ] Cleanout / access panels in service layer

ERV:

[ ] ERV unit mounted per manufacturer's instructions
[ ] Outdoor air intake duct routed to exterior with intake hood and damper
[ ] Exhaust duct routed to exterior with hood and damper
[ ] Intake separated from exhaust per code (10 ft minimum)
[ ] Intake separated from contamination sources (dryer vent, range hood discharge, etc.)
[ ] Condensate drain on ERV
[ ] Power connection per electrical
[ ] Filters installed and accessible
[ ] Duct connections sealed

DEHUMIDIFIER:

[ ] Whole-house dehumidifier installed per plan
[ ] Ducted to ventilation system per plan
[ ] Condensate drain
[ ] Power connection per electrical

RANGE HOOD:

[ ] Range hood ducted to exterior (not recirculating)
[ ] Smooth-walled metal duct
[ ] Maximum length per plan and manufacturer
[ ] Termination per code (3 ft from openings, with damper)

MAKEUP AIR (if applicable):

[ ] Dedicated makeup air duct
[ ] Interlocked damper with range hood
[ ] Insulated duct outside the envelope

DRYER VENT:

[ ] Smooth-walled rigid metal duct (no flex except for very short transition)

```

```
INTERIOR PARTITION SOUND INSULATION:

UNDER-SLAB INSULATION (already verified at slab inspections, but re-check):
```

## Final Notes on Inspection Strategy

**1. Build the relationship.** A good relationship with each inspector — building, electrical, plumbing, mechanical — makes the entire process smoother. Be respectful, prepared, and professional. Never try to talk an inspector out of a code requirement.

**2. Schedule conservatively.** Inspectors are busy; same-day inspections are rare. Schedule 24-48 hours in advance, sometimes longer. Plan the work so the next phase doesn't depend on instantaneous inspection.

**3. Don't assume the inspector knows the design's special features.** This design has unusual elements (interconnect box, service layer, FRP wall ties, individual vents instead of stacks). Bring the relevant section of this document or the approved plans to point out non-standard items.

**4. Document everything.** Photographs of every wall before it's covered, every penetration, every connection. Future you will thank present you.

**5. When something fails inspection, take it as data, not as defeat.** Failures expose problems while they can still be fixed cheaply.

**6. Keep the binder updated.** Every signed checklist goes immediately into the project binder. By CO, the binder is a complete record of every inspection, every test, every milestone — invaluable for resale, future renovations, and personal reference.
