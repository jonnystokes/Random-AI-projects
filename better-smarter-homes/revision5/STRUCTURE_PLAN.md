## Expansion Method

For each chapter:

1. Read the target Revision 5 chapter.
2. Read the crosswalk entry.
3. Read the mapped predecessor, Revision 3 sources, and Revision 2 source-history files.
4. Read the matching research file if the user has supplied research or the chapter needs it.
5. Expand with the quad-layer model.
6. Keep the chapter positive, creative, and useful while still naming real risks.
7. Preserve useful source material. Do not silently compress.
8. Update `AI_TODO.md`.

## Final Passes

After chapter expansion:

1. Build the code lookup appendix.
2. Write the glossary appendix last, using `GLOSSARY_POLICY.md`.
3. Regenerate the table of contents.
4. Run checks for em dashes, stale references, displayed forms, placeholders, and bad inherited AI phrasing.
