# Chapter 2: Oregon Code And Compliance Map

This chapter describes the Oregon residential code system as it applies to this project. It identifies the layers of authority, the specialty codes that control different parts of the house, the design paths the code recognizes, the inspection points that gate the build, and the records that prove the work was done correctly.

The code system is large. Once the layers are sorted, it has a clear logic. Each layer answers a different question, and the most common mistake is asking one layer to answer a question that belongs to another. The Legal, Permits, Owner-Builder Rules, And Inspections chapter takes the legal-path detail; this chapter is the navigation map.

## 2.1 The Oregon Rule Stack

Oregon does not use a single residential code. State law authorizes a family of specialty codes, administrative rules, and local procedures that together control building work.

**Simple**

Building rules in Oregon are stacked in layers. State laws sit at the top. State agencies write rules that fill in the details. The rules adopt specialty codes for buildings, electrical, plumbing, mechanical, and energy. Local building departments handle the day-to-day permits and inspections under those state rules. Approved drawings, manufacturer instructions, and adopted standards round out the stack.

**Professional**

The rule stack, top to bottom:

| Layer | What it does | What it controls for this house |
|---|---|---|
| Oregon Revised Statutes (ORS) | State laws passed by the legislature | Authority for building codes, contractor licensing, owner-builder rules, disclosures, and enforcement |
| Oregon Administrative Rules (OAR) | Agency rules that implement state law | Adoption of specialty codes, permit procedures, certificate-of-occupancy procedures, agency program detail |
| Oregon specialty codes | Technical building, electrical, plumbing, mechanical, and energy rules | The actual house systems and their inspections |
| Local jurisdiction process | Plan review, permit issuance, inspection scheduling, correction notices, approval records | The local submission and inspection workflow |
| Approved plans and engineering | Project-specific drawings, calculations, specifications, and stamped sheets | The legal design for this house in particular |
| Referenced standards | Standards adopted by codes (ASTM, ACI, ASCE, ASHRAE, NFPA, UL, ANSI, TMS, and others) | Test methods, materials, equipment ratings, fire ratings, listed assemblies |
| Manufacturer instructions | Required installation rules for listed products | How a specific product must be installed, supported, sealed, vented, tested, and maintained |

The exact code edition in force at permit application is a permit-time fact. Oregon updates codes, amendments, errata, and phase-in dates over time. The structure of the stack is stable; the edition is not. Confirm the adopted edition with the permit-issuing jurisdiction before submitting plans.

**Code**

```
ORS Chapter 455: Building Code.
  - State authority for the residential, commercial, and specialty building codes.
  - Authorizes the Building Codes Division (BCD) to adopt codes by rule.
  - Contains the owner-built dwelling structural exemption (ORS 455.320) and the rural-county exemption framework (ORS 455.330–455.350).
  - ORS 455.055 establishes the uniform permit, inspection, and certificate-of-occupancy requirements.

ORS Chapter 701: Construction Contractors and Contracts.
  - Licensing framework administered by the Construction Contractors Board (CCB).
  - Owner-occupier exemption from CCB licensure under ORS 701.010, with the intent-to-sell prima facie test.
  - Homeowner-applicant statement framework at ORS 701.325.

OAR Chapter 918: Building Codes Division Rules.
  - State-level building, electrical, plumbing, mechanical, and energy code administration.
  - OAR Chapter 918 Division 480 covers one- and two-family dwelling specialty-code administration.

2023 Oregon Residential Specialty Code (ORSC), based on the 2021 IRC.
  - Effective October 1, 2023; mandatory April 1, 2024.
  - Chapter 1 effective and mandatory October 1, 2023; Chapters 2–44 and appendices effective October 1, 2023, mandatory April 1, 2024.
  - Confirm the adopted edition with the jurisdiction at permit application; the edition phases in by chapter.

Oregon Building Codes Division: oregon.gov/bcd.
  - Adopted codes online, statewide forms, code-edition phase-in announcements, BCD program guides.
  - Cite-It Write-It checklist: BCD's plan-review compliance reference.

Local jurisdiction adoption.
  - Each city or county administers the state codes through its own building department.
  - Local amendments may apply where the state allows them.
```

## 2.2 The Main Code Lanes For This House

A concrete house still contains the same systems as any other dwelling: structure, water supply, drains, power, heat, ventilation, insulation, egress, fire safety, sanitation, and final approval for occupancy. The clean way to read the code is one lane at a time.

**Professional**

| Work area | Primary lane | What that lane controls |
|---|---|---|
| Residential building | Oregon Residential Specialty Code (ORSC) | Building planning, structure, foundations, walls, floors, roofs, stairs, openings, fire separation, safety, inspections, and occupancy |
| Electrical | Oregon Electrical Specialty Code (OESC), based on the National Electrical Code with Oregon amendments | Service, panels, grounding, bonding, branch circuits, receptacles, lighting, protection devices, equipment, electrical inspections |
| Plumbing | Oregon Plumbing Specialty Code (OPSC) | Water supply, drain-waste-vent, fixtures, water heaters, backflow, tests, plumbing inspections |
| Mechanical | Oregon Mechanical Specialty Code (OMSC) | HVAC equipment, ventilation, exhaust, ducts, hydronics, combustion air where applicable, appliance clearances, mechanical inspections |
| Residential energy | ORSC Chapter 11 (residential energy provisions) | Insulation, air sealing, windows, ducts, mechanical ventilation, energy compliance path, related testing |
| Onsite wastewater | DEQ rules under OAR Chapter 340 Division 71 and local septic administration where applicable | Septic feasibility, permits, design, installation, inspection, approval |
| Water wells | OWRD rules under OAR Chapter 690 and ORS 537.747 where applicable | Well drilling, well logs, water-source legality, related records |
| Fire and fuel systems | State Fire Marshal rules, fuel-gas rules, product listings | Fire safety, LP gas, special fuel systems, licensed work requirements |
| Workplace safety | Oregon OSHA rules under OAR Chapter 437 where applicable | Trenching, excavation, fall protection, confined spaces, equipment, jobsite safety duties |
| Engineering and standards | Approved engineering and adopted standards (ACI, ASCE, ASTM, ASHRAE, NFPA, UL, ANSI, TMS) | Concrete design, loads, reinforcing, materials, test methods, equipment ratings, fire ratings, listed assemblies |

**Code**

```
ORSC: Oregon Residential Specialty Code.
  - 2023 edition based on the 2021 IRC, adopted by OAR 918-480-0005.
  - Covers detached one- and two-family dwellings and townhouses up to three stories.
  - Includes administrative provisions (Chapter 1), building planning (Chapter 3), foundations (Chapter 4), walls (Chapter 6), roofs (Chapter 8–9), and energy efficiency (Chapter 11).

OESC: Oregon Electrical Specialty Code.
  - Adopts the National Electrical Code with Oregon amendments under OAR Chapter 918 Division 305.
  - Covers electrical installations, equipment, conductors, grounding, bonding, and overcurrent protection for residential occupancies.

OPSC: Oregon Plumbing Specialty Code.
  - Adopted under OAR Chapter 918 Division 750.
  - Covers water supply, drain-waste-vent, fixtures, gas piping in some applications, and plumbing testing.

OMSC: Oregon Mechanical Specialty Code.
  - Adopted under OAR Chapter 918 Division 440.
  - Covers HVAC equipment, ventilation, ducts, hydronics, combustion air, and appliance clearances.

ORSC Chapter 11 (residential energy provisions).
  - Effective October 1, 2023; mandatory April 1, 2024.
  - Table N1101.1(1) provides the standard base-case envelope values.
  - Table N1101.1(2) provides additional measures required for new conditioned space.
  - Concrete-specific note: a concrete roof or unusual concrete envelope often cannot use the simple prescriptive path and instead requires a UA tradeoff calculation or another accepted performance path.

OAR Chapter 340 Division 71: Oregon onsite wastewater treatment and disposal rules.
  - DEQ administered, often delegated to county health departments.
  - Site evaluation, system permit, installation, pre-cover inspection, certificate of satisfactory completion.

OAR Chapter 690 Divisions 200–240 and ORS 537.747: water-supply well construction.
  - Landowner Well Permit available under OAR 690-205-0175 for an owner who is not a licensed Water Supply Well Constructor.
  - Construction must meet the same OAR 690-200 through 690-240 standards as licensed drillers.

ORS Chapter 480 and OAR Chapter 837 Division 30: State Fire Marshal LP-gas licensing.
  - No homeowner exemption for LP gas work.

OAR Chapter 437: Oregon OSHA rules for workplace safety.
  - Excavation and trenching (Division 3 Subdivision P), fall protection, confined spaces.
```

This is a concrete-home book. Wood framing rules are not reproduced in detail. Wood appears only where a wood detail intersects the project: roof framing if the roof is wood-framed, formwork, opening framing, fire separation, or comparison with a concrete or masonry assembly.

## 2.3 Which Document Answers Which Question

Construction questions become much easier when sorted by the kind of answer they need.

| Question | First place to look |
|---|---|
| Am I legally allowed to act as the owner-builder? | ORS, OAR, BCD homeowner guidance, the Legal, Permits, Owner-Builder Rules, And Inspections chapter |
| Which permit path applies to this work? | Local building department or Oregon ePermitting path |
| What must this wall, slab, wire, pipe, vent, drain, appliance, or window satisfy? | Applicable Oregon specialty code and approved plans |
| Who must design this detail? | Code prescriptive path, engineer of record, local building official, or specialty professional |
| How is this product installed? | Listing, label, and manufacturer instructions |
| How is this work tested? | Applicable code, referenced standard, approved test method, or inspector requirement |
| Can I cover this work? | Passed inspection and project documentation |
| Can I occupy the home? | Final approval (CO) or lawful temporary occupancy approval (TCO) |

A handful of failure patterns belong in this section because they show up repeatedly when owner-builders meet the code system for the first time:

- A product brochure does not override code. Manufacturer instructions are required, but they cannot allow installation that violates the code.
- A construction video does not override approved drawings.
- A practice that is normal in another state does not override Oregon. Codes vary.
- A summary inside this book does not override the official source. The book is a working reference; the official source is the legal authority.
- A heavier-looking assembly is not automatically compliant. Compliance is a property of the whole assembly under the actual site conditions.

Concrete makes this rule especially important. Adding concrete can help a design, but it can also add load, change seismic behavior, complicate reinforcement, and break insulation or connection details. Code compliance is a property of the whole assembly, not a property of any single material or thickness.

## 2.4 Prescriptive, Engineered, And Alternative Paths

The code recognizes three design paths. A concrete house in Oregon usually uses two of them and sometimes all three.

**Simple**

A prescriptive path is a recipe. The code spells out what to build, and the work follows the recipe. An engineered path is a design. A licensed professional sizes the system for the actual house, soil, and loads. An alternative-method path is a special approval. The building official accepts a different way of meeting the code's intent.

**Applied**

Use this decision flow when classifying a structural or building-envelope element:

1. Does the prescriptive code section in ORSC cover this element under all the limits (geometry, seismic design category, load, height)?
2. If yes, the prescriptive path is available. Confirm with the engineer of record that the prescriptive values match the specific application.
3. If no, design under R301.1.3 (engineered design) using accepted engineering practice and the relevant referenced standard (ACI 318, ACI 332, PCA 100, TMS 402, ASCE 7, others).
4. If a non-prescriptive method is preferred (innovative system, unusual material, tested assembly), submit an alternative-method approval request to the building official under ORSC R104.11.
5. Carry the chosen path into permit submittal: prescriptive table cited, engineered drawings stamped, or alternative-method approval letter on file.

**Professional**

| Path | What it means | Best fit |
|---|---|---|
| Prescriptive | The code provides a direct method and the design fits inside the listed limits | Ordinary details that fall clearly inside the code tables and standard assumptions |
| Engineered | A licensed professional designs or verifies the system for the actual loads, soil, geometry, and materials | Reinforced concrete, unusual foundations, retaining conditions, seismic design, large openings, complex load paths, nonstandard assemblies |
| Alternative method | The building official may approve another method when the required showing is made | Innovative systems, unusual materials, tested assemblies, or details that meet the intent of the code by another approved route |

For most concrete and reinforced-masonry residences in western Oregon, engineered design is the default. Seismic Design Category D0, D1, or D2 covers the Willamette Valley, the I-5 corridor, and the coast. Several prescriptive paths (notably ORSC R608 above-grade concrete walls) are available only in SDC C, which is essentially the eastern half of the state. The Structural System And Concrete Design chapter explains why and identifies the specific code triggers (seismic design category, two-wythe walls, irregular building conditions, nonstandard wall heights, expansive soil).

The prescriptive paths in ORSC R608 (above-grade concrete walls) and ORSC R606 (masonry walls) remain useful as vocabulary and minimum-expectation references. They should not be assembled into a recipe for a nonstandard concrete home.

The practical habit is straightforward:

- use prescriptive details where they fit the project's geometry, soil, and seismic conditions
- use engineered details where the system carries unusual demand
- identify any alternative-method approval before plan review, not during inspection
- keep product listings and installation instructions with the permit record
- treat field changes as design changes when they affect approved work

Code questions identified after concrete has cured are no longer paperwork problems. Resolve them before placement. Once the concrete has set, exposing and correcting an error is expensive, and some errors cannot be corrected without partial demolition.

**Code**

```
ORSC R301.1: residential design criteria.
  - General requirement that buildings be designed for the loads in this code.
  - Where prescriptive limits are exceeded, R301.1.3 directs the design to accepted engineering practice.

ORSC R301.1.3: engineered design path (formerly the "nonprescriptive" path).
  - Structural elements that exceed ORSC prescriptive limits must be designed by accepted engineering practice.
  - The engineer of record stamps the structural drawings and supporting calculations.
  - The 2023 ORSC reframes this as nonprescriptive design; the function is unchanged.

ORSC R301.2.2: seismic provisions.
  - Adoption of seismic design category and the reinforcing requirements that follow.
  - SDC D0, D1, D2 trigger expanded reinforcement for foundations, walls, and floor diaphragms.

ORSC R301.2.2.5: concrete construction provisions.
  - Above-grade concrete walls in SDC D0, D1, D2 must comply with PCA 100 or be designed in accordance with ACI 318.
  - ACI 332-20 covers the same residential scope as a residential-specific code referenced by IRC.

ORSC R301.2.2.6: irregular building conditions.
  - Lists eight irregularity conditions that trigger engineered analysis for the entire story.
  - Examples: offsets in vertical lateral elements, large openings in diaphragms, mass irregularities, mixing wood framing above masonry/concrete in stories above grade plane.

ORSC R608: prescriptive exterior above-grade concrete walls.
  - Available only in SDC C with limits on wall height, opening size, and reinforcement.
  - Most western Oregon sites are SDC D0 or higher; R608 is unavailable there.

ORSC R606: prescriptive masonry wall provisions.
  - Available with limits on bar size, spacing, lap length, grout, mortar type, and seismic category.

PCA 100: Prescriptive Design of Exterior Concrete Walls for One- and Two-Family Dwellings.
  - Referenced by ORSC R301.2.2.5 as a path for above-grade concrete walls in SDC D0/D1/D2.

ACI 318: Building Code Requirements for Structural Concrete.
  - Primary engineered structural concrete design standard.
  - Covers cast-in-place walls, slabs, beams, columns, footings, retaining walls, foundation walls, anchorage, development length, lap splice, cover, and exposure classes.

ACI 332-20: Code Requirements for Residential Concrete.
  - Residential-specific code with prescriptive tables.
  - Covers footings, foundation walls, slabs-on-ground, above-grade walls in scope, and Chapter 12 expansive-soil residential design.

TMS 402-22: Building Code Requirements for Masonry Structures.
  - Engineered masonry design standard.
  - Composite, noncomposite, and veneer wall classifications under §5.1.4.

ORSC R104.11: alternative materials, design, and methods of construction.
  - The building official may approve any alternative material, design, or method of construction not specifically prescribed by the code, provided the proposed alternative is at least equivalent in quality, strength, effectiveness, fire resistance, durability, and safety.
  - Submittal typically includes test data, engineering calculations, and supporting documentation.
```

## 2.5 Owner-Builder Position In The Code Map

The owner-builder path is a legal role with specific duties. It affects who pulls the permit, signs the homeowner statement, performs regulated work, hires licensed subcontractors, schedules inspections, carries jobsite responsibility, and documents corrections.

There is no statewide three-year resale clock for owner-built homes. Oregon's owner-builder framework uses an intent-to-sell test under contractor-licensing law (ORS 701.010(5)), a five-year cooldown on the structural-code exemption (ORS 455.320), a separate five-year cooldown on the rural-county exemption (ORS 455.335), a 75-day post-completion lien-notice obligation (ORS 87.007 and ORS 87.093), and a separate federal capital-gains framework under IRC §121. The Legal, Permits, Owner-Builder Rules, And Inspections chapter walks through each of these with citations and resolved positions.

The point for the code map is narrower: decide who is acting in each role before regulated work begins. Homeowner, owner-builder, contractor, trade contractor, engineer, inspector, local jurisdiction, and brand entity are not interchangeable. The permit, the license, the inspection record, and the certificate of occupancy each name a person or entity, and those names need to match the actual work.

The trade-side scope has a few hard rules that deserve a place on the code map even though the legal chapter handles them in detail:

- LP gas: hard stop. ORS 480.432 requires State Fire Marshal licensing for any LP gas installation, fitting, or piping work. No homeowner exemption.
- Septic: separate DEQ permit path. Owner can install with their own permit per OAR 340-071.
- Water wells: separate OWRD path. Landowner Well Permit available under OAR 690-205-0175.
- Refrigerant work: EPA Section 608 certification required regardless of homeowner status.

## 2.6 Inspection Checkpoints

Inspections are scheduled gates in the build sequence. They allow regulated work to proceed once each stage has been verified, and they create the record that the work was checked before being covered.

For a concrete house, the major checkpoints are listed below. The Inspection And Approval Sequence chapter provides the readiness criteria for each inspection, the corrective steps when work fails, and the records that result.

| Inspection | When | What gets verified |
|---|---|---|
| Permit application and plan review | Before any regulated work | Approved drawings, calculations, engineering |
| Erosion control or site inspection | Where required by the local jurisdiction | Erosion-control measures, site-disturbance limits |
| Footing | Before concrete placement | Footing geometry, reinforcement, anchor bolts, soil bearing surface, UFER ground |
| Foundation drainage and dampproofing | Before backfill | Drain rock, perimeter drain, dampproofing or waterproofing membrane, capillary break |
| Under-slab | Before slab placement | Subgrade, capillary break, vapor retarder, soil-gas retarder where applicable, under-slab insulation, sleeves |
| Rough plumbing | Before walls or chases close | DWV pressure or static test, water-supply rough, gas piping pressure test where applicable |
| Rough electrical | Before walls close | Boxes, conductors, panel rough, grounding, bonding, low-voltage where included |
| Rough mechanical | Before walls or ceilings close | Equipment, ducts, gas piping, ventilation, exhaust, refrigerant lines |
| Insulation and air sealing | Before drywall | Insulation type, depth, continuity, air-sealing penetrations |
| Energy and blower door | Where the compliance path requires testing | Blower-door result, duct-leakage test result if applicable |
| Final building, electrical, plumbing, mechanical | Each discipline finals separately | Each discipline's final inspection record |
| Site-development final | Before CO | Permanent erosion control, stormwater, landscape, address |
| Certificate of occupancy | All disciplines final and Form 4823 submitted | CO issued; binder closes |

For concrete work, the inspection schedule has to be coordinated with the concrete schedule. Trucks arrive on a fixed window, weather changes, crews tire, forms can move, reinforcement gets buried, and curing begins whether the inspector has visited or not. An inspector cannot approve work that is already hidden. The schedule that works pulls the inspection in before the pour, not after.

## 2.7 Code Blocks In This Book

Technical chapters use `Code` blocks as signposts to the controlling sources. Each `Code` block names the lane, gives the colon-format citation, and explains what the source actually says (the rule, the table reference, the limit, the geometry, the test method, the inspection trigger, or other context). Multiple lines per citation are normal and often used.

A `Code` block does not pretend to certainty when the answer depends on jurisdiction, code edition, soil condition, seismic category, wind exposure, product listing, or engineered design. In those cases, the block names the variable plainly and points to the source that controls the local answer.

The book is meant to substitute for opening the official code book in routine situations. The Code Lookup And Compliance Cross-Reference appendix and the Glossary at the end of the book support topic-based lookup when the book location is not obvious.

## 2.8 The Project Binder

The binder is where the code map turns into proof. Keep the binder organized from permit application onward.

The binder should contain:

- permit applications, approvals, and revisions
- approved plans, including any sheets revised after issuance
- plan-review comments and the responses to each
- inspection cards, inspection approvals, and correction notices for each discipline
- the signed BCD Property Owner Statement and any local equivalent
- engineering letters, stamped sheets, calculations, and special inspection records
- product data, listings, and manufacturer installation instructions
- concrete batch tickets, soil reports, septic approvals, well records, OWRD landowner permit and well log, SFM tank installation report if applicable
- photographs taken before each cover stage
- subcontractor CCB and BCD license records and certificates of insurance
- BCD Form 4823 contractor information notification
- final approval and occupancy records (CO or TCO and any extensions)

The binder protects the project during construction, helps the inspector at each visit, supports repairs and resale, and lets a future occupant or contractor understand what was built without guessing. The Documentation, Maintenance, And Future Upgrades chapter covers binder organization, retention, and digital backup in detail.
