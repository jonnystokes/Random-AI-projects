# Appendix A: Standards And Reference Index

This appendix is a map of source families. It is not a copy of the code book, a replacement for paid standards, or a complete list of every rule that could affect a house.

Use this index to know where a requirement comes from, which authority owns it, and what must be rechecked before the final build documents are issued.

The working URL list belongs outside the reader-facing manuscript for now. This appendix names the source families and explains how to use them without turning the book into a code dump.

## Index Scope

**Simple**

This index tells you where to look.

It does not contain every rule.

**Applied**

Use the index when you need to know:

- Which Oregon code family controls a trade.
- Which agency handles a site, water, septic, hazard, or safety topic.
- Which standards family may control a test or product.
- Which source needs to be checked before using an exact value.
- Which topics are still deferred for the research pass.

Do not use this index as the final answer for a permit, inspection, product installation, or professional design.

**Professional**

The index is a source-control tool. It keeps code, agency, standard, manufacturer, and research paths visible without overloading every chapter with citation mechanics.

The final manuscript should preserve this distinction: the technical chapters explain the work, the `Code` blocks identify the control path, and this index helps find the source family.

**Code**

The official code, adopted standard, approved plan, product listing, manufacturer instruction, authority having jurisdiction, and required inspection control the final answer.

This index does not override them.

## How To Use This Index

**Simple**

Start with the topic.

Then find the rule family.

**Applied**

Use this pattern:

1. Identify the work: structure, plumbing, electrical, HVAC, septic, well, envelope, testing, or documentation.
2. Find the source family in this index.
3. Check the current official source.
4. Check the approved plans.
5. Check product instructions.
6. Ask the building department, engineer, licensed trade, manufacturer, or other qualified source when the answer is not clear.

Never size, install, test, or approve work from memory.

**Professional**

The index should be used with project context. Code edition, jurisdiction, permit date, plan-review comments, site conditions, product selection, engineering scope, and inspection preferences can change which source controls the final decision.

For exact values, use the current official source and the approved drawings. This book can explain the path, but the current source controls the number.

**Code**

Do not reproduce copyrighted code or standards text into the manuscript. Summarize only what is needed, cite the source family, and keep the exact official text in the official source.

When in doubt, quote less and verify more.

## Oregon Building Code Family

**Simple**

Oregon does not use one single building book.

It uses a family of specialty codes.

**Applied**

For this house, the main Oregon code lanes are:

| Work | Source Family |
|---|---|
| Residential building and structure | Oregon Residential Specialty Code |
| Electrical work | Oregon Electrical Specialty Code |
| Plumbing work | Oregon Plumbing Specialty Code |
| Mechanical work | Oregon Mechanical Specialty Code |
| Residential energy | Oregon residential energy provisions |
| Legal and administrative rules | Oregon Revised Statutes and Oregon Administrative Rules |
| Permits and inspections | Local building department and Oregon permit resources |

Check the code edition at permit time.

**Professional**

The Oregon Building Codes Division is the main state source used in this draft for adopted specialty-code framing, residential code scope, electrical code scope, plumbing code scope, mechanical code scope, residential energy framing, permit services, laws, and rules.

National model codes matter because Oregon adopts from model-code families. Oregon amendments matter because the Oregon-adopted version controls the project.

**Code**

Use the Oregon-adopted specialty code, Oregon amendments, current errata, interim amendments where applicable, approved plans, product listings, manufacturer instructions, and local inspection process.

Do not use the unamended national model code as the final Oregon rule unless the Oregon path accepts it for that scope.

## Permit, Inspection, And Owner-Builder Sources

**Simple**

Permits and inspections are not side paperwork.

They control when work can start, what can be covered, and when the house can be occupied.

**Applied**

Useful source families:

| Topic | Source Family |
|---|---|
| Permit applications | Local building department and Oregon permit resources |
| Online permit workflow | Oregon ePermitting resources |
| Homeowner responsibility | Oregon homeowner acknowledgement material |
| Contractor licensing | Oregon Construction Contractors Board and Oregon law |
| Owner-builder limits | Oregon statutes, rules, local interpretation, and professional advice |
| Occupancy approval | Local building department and Oregon residential occupancy rules |
| Engineering practice | Oregon engineering board sources and professional licensing rules |

Keep permit and inspection records in the project binder.

**Professional**

The permit path is project-specific. City, county, rural site, septic, well, driveway, fire access, utility, environmental, and design conditions can change the approval path.

The owner-builder path should be treated as a responsibility structure, not a loophole.

**Code**

Legal, licensing, owner-builder, occupancy, contractor, tax, business, and professional-practice issues can change. Verify the current source before relying on them.

Where the project crosses into paid work, professional services, LPG, septic, well, engineering, or contractor activity, do not assume the homeowner path still controls.

## Site, Soil, Hazard, And Excavation Sources

**Simple**

The site needs its own sources.

The ground, water, slope, and hazards are not solved by house plans alone.

**Applied**

Source families used or deferred for site work:

| Topic | Source Family |
|---|---|
| Soil survey | NRCS Web Soil Survey and related soil data |
| Oregon geologic hazards | DOGAMI hazard tools and map services |
| Landslide information | DOGAMI landslide inventory and susceptibility sources |
| Site design criteria | Oregon design criteria resources |
| Utility locating | Oregon 811 and utility-locate resources |
| Excavation safety | OSHA trenching and excavation guidance |
| Geotechnical design | Engineer or geotechnical professional with accepted standards |

Use these sources before excavation, foundation design, drainage planning, or site-risk decisions.

**Professional**

Desktop tools identify risk. They do not prove bearing capacity, settlement behavior, liquefaction response, expansive clay movement, groundwater behavior, or final foundation design.

Use desktop data, field evidence, test results, and professional review together. Do not turn a map layer into a foundation design.

**Code**

Where soil, slope, fill, erosion, groundwater, excavation, or mapped hazard conditions create concern, the building official, approved plans, and engineering path may require more documentation.

Owner screening does not replace required geotechnical design or excavation safety requirements.

## Structural Concrete And Masonry Sources

**Simple**

Concrete structure needs more than common sense.

It needs code, engineering, drawings, inspections, and test records.

**Applied**

Relevant source families:

| Topic | Source Family |
|---|---|
| Residential structure | Oregon Residential Specialty Code |
| Site loads and design criteria | Oregon design criteria resources |
| Concrete foundation and wall paths | Oregon residential code, amendments, engineering, and accepted standards |
| Structural concrete | ACI standards where adopted, referenced, or accepted |
| Residential concrete | ACI residential concrete resources where applicable |
| Concrete testing | ASTM and project-specified test standards where required |
| Product systems | Manufacturer instructions and listings |

Use the approved structural drawings for final bar size, spacing, cover, laps, embeds, openings, and placement requirements.

**Professional**

The manuscript identifies ACI structural concrete and residential concrete standards only at a high level where already source-supported. Exact ACI, ASTM, PCA, masonry, grout, reinforcement, inspection, and testing requirements need final standards review before they become build instructions.

Prescriptive concrete paths and engineered concrete paths must not be blended casually.

**Code**

If the assembly is outside the prescriptive code path, the approved engineered design controls. If the approved drawings conflict with memory, habit, a blog post, or an old table, stop and resolve the conflict before building.

Do not reproduce paid standards text into this book.

## Envelope, Energy, Radon, And Indoor-Air Sources

**Simple**

Comfort and health come from systems working together.

Air, water, heat, radon, ventilation, and moisture all need source-backed decisions.

**Applied**

Relevant source families:

| Topic | Source Family |
|---|---|
| Residential energy | Oregon residential energy provisions and BCD compliance tools |
| Air leakage testing | Oregon energy compliance tools and accepted test methods |
| Radon testing and action guidance | Oregon Health Authority and EPA radon resources |
| Radon-resistant construction | Oregon residential code path, EPA guidance, and relevant radon standards |
| Moisture and envelope testing | Product instructions, accepted standards, and professional diagnostics |
| Ventilation comfort and IAQ | Mechanical code, energy path, ASHRAE where applicable, and product instructions |

Do not use a general comfort target as a code requirement unless the source says so.

**Professional**

Energy, radon, and indoor-air requirements are source-sensitive. The final path depends on code edition, compliance route, county or local radon applicability, selected ventilation system, blower-door method, product instructions, and inspection process.

Use current state and federal health guidance for health topics. Use current code and approved energy documents for compliance.

**Code**

Radon action levels, radon-control requirements, air-leakage reporting, ventilation verification, insulation requirements, and energy compliance documents must be checked against current official sources and the approved compliance path.

Do not invent thresholds or testing intervals.

## Plumbing, Wells, Septic, And Wastewater Sources

**Simple**

Water has several rule paths.

Clean water, wastewater, wells, septic, graywater, and backflow are not the same problem.

**Applied**

Relevant source families:

| Topic | Source Family |
|---|---|
| Water supply and plumbing | Oregon Plumbing Specialty Code |
| Drain, waste, and vent | Oregon Plumbing Specialty Code |
| Pressure control and expansion | Current plumbing code and product instructions |
| Private wells | Oregon Water Resources Department and health-testing sources |
| Water quality | Oregon Health Authority, accredited labs, and system-specific requirements |
| Septic and onsite wastewater | Oregon DEQ and county environmental health path |
| Graywater | Oregon DEQ graywater rules and permit path |
| Fixtures and equipment | Product listings and manufacturer instructions |

Do not size pipe, slopes, vents, backflow, wells, septic, or graywater from memory.

**Professional**

The plumbing chapters intentionally defer exact sizing tables, slopes, trap-arm limits, developed lengths, backflow device choices, cleanout clearances, sewage ejector details, water-treatment requirements, and septic/well design requirements until current source review.

Source family is not enough. The actual design must match fixture load, pressure, developed length, site grade, soil, water source, equipment, jurisdiction, and approved plans.

**Code**

Potable water protection, DWV, venting, sewer, septic, graywater, wells, backflow, pumps, water heaters, and final plumbing approval must follow the current adopted code, applicable agency rules, approved plans, product listings, and inspection process.

Where public health is involved, do not substitute owner preference for the official path.

## Electrical, Low-Voltage, And Power Sources

**Simple**

Electrical work needs the current electrical code.

A working light is not proof that wiring is compliant.

**Applied**

Relevant source families:

| Topic | Source Family |
|---|---|
| Service, panels, grounding, and feeders | Oregon Electrical Specialty Code |
| Branch circuits | Oregon Electrical Specialty Code |
| GFCI, AFCI, receptacles, lighting, and boxes | Oregon Electrical Specialty Code |
| Low-voltage and communications wiring | Electrical code, product instructions, and communications standards where applicable |
| Solar, batteries, EV, generator, and transfer equipment | Electrical code, utility rules, product listings, and manufacturer instructions |
| Smoke and CO alarms | Residential code, electrical code, product listings, and local inspection process |

Check the adopted edition before design and again before permit.

**Professional**

The electrical chapters preserve the planning logic but defer exact conductor sizes, ampacity, voltage drop, derating, fill, circuit ratings, receptacle spacing, protection locations, working clearances, service size, grounding details, surge protection, generator, battery, EV, solar, and low-voltage rules.

Those details must come from the adopted code, approved load calculation, listed equipment, product instructions, utility requirements, and inspection path.

**Code**

Do not energize, cover, modify, or label electrical work as complete until the required approval path is satisfied.

Use licensed or qualified people where the law, hazard, utility, inspection, or equipment requires it.

## Mechanical, Ventilation, And HVAC Sources

**Simple**

Mechanical systems are not finished when equipment turns on.

They need code, startup, ventilation, drainage, controls, and commissioning.

**Applied**

Relevant source families:

| Topic | Source Family |
|---|---|
| Mechanical systems | Oregon Mechanical Specialty Code |
| Ventilation and exhaust | Mechanical code, energy path, ASHRAE where applicable, and product instructions |
| Heat pumps and refrigerant systems | Mechanical code, product instructions, EPA rules where applicable, and qualified technicians |
| Hydronic and radiant systems | Mechanical code, plumbing/electrical coordination, product instructions, and commissioning records |
| Dryer and kitchen exhaust | Mechanical code, manufacturer instructions, and local inspection process |
| Controls | Product listings, manufacturer instructions, electrical requirements, and commissioning plan |

Do not use equipment startup as the only commissioning test.

**Professional**

The final HVAC source path depends on load calculation, envelope performance, ventilation method, exhaust strategy, makeup-air behavior, hydronic layout, refrigerant rules, controls, humidity targets, and manufacturer startup requirements.

The book should explain what to verify, not invent rates, duct sizes, refrigerant procedures, or balancing values.

**Code**

Mechanical, ventilation, exhaust, refrigerant, combustion if any, hydronic, condensate, dryer exhaust, kitchen hood, controls, and equipment-startup requirements must follow the current adopted code, product listings, manufacturer instructions, and inspection process.

Refrigerant work is not an owner-builder guesswork task.

## Product, Manufacturer, Listing, And Warranty Sources

**Simple**

A product has its own rules.

The label and instructions matter.

**Applied**

Check product sources for:

- Installation instructions.
- Listings and approvals.
- Compatibility.
- Fasteners.
- Adhesives and sealants.
- Substrate requirements.
- Temperature and weather limits.
- Clearances.
- Startup.
- Maintenance.
- Warranty conditions.
- Replacement parts.

Keep current instructions with the project binder.

**Professional**

Manufacturer instructions often control details that the code does not spell out: substrate preparation, fastening pattern, curing condition, clearances, pipe support, wire termination, flashing sequence, coating thickness, startup procedure, service interval, and warranty record.

The approved product submittal should match the product actually installed.

**Code**

Listed equipment and approved products must be installed according to their listings and manufacturer instructions. Substitutions should be reviewed before installation, not after failure.

Do not use a similar product's instructions for a different product.

## Deferred Standards And Final Research

**Simple**

Some standards are named now, but not finished yet.

Those need research before the final code-heavy rewrite.

**Applied**

Deferred source families include:

| Area | Needs Final Research |
|---|---|
| Concrete testing | ASTM methods, technician qualifications, lab reports, acceptance criteria. |
| Structural concrete | ACI and related standards actually accepted for the final design. |
| Masonry and grout | Standards, inspection triggers, reinforcement, and testing path. |
| Ventilation | ASHRAE and Oregon-specific requirements where applicable. |
| Radon construction | Current Oregon path, EPA guidance, and ANSI/AARST where applicable. |
| Electrical details | Exact adopted-code requirements for final circuit, panel, grounding, and low-voltage design. |
| Plumbing details | Exact OPSC tables, slopes, sizes, cleanouts, backflow, and venting. |
| HVAC commissioning | Manufacturer and standards-based commissioning requirements. |
| Smart-home and security | Low-voltage, privacy, cybersecurity, access-control, and listing requirements. |
| Business and brand | Licensing, tax, insurance, advertising, platform, and IP requirements. |

Keep soft language until these are verified.

**Professional**

This index should be revised after the research pass. At that point, each chapter can point to the exact source family that controls its Code blocks, and the glossary can be checked against the final terminology.

Do not fill missing standards by guessing from common practice.

**Code**

If the final source cannot be verified, the manuscript should say so directly and avoid firm numbers, procedures, legal conclusions, or approval claims.

Unverified precision is worse than clear uncertainty.

## Update Rule

**Simple**

This index has to stay current.

Codes and products change.

**Applied**

Update the index when:

- A code edition changes.
- Oregon publishes amendments or interim changes.
- A local jurisdiction gives a project-specific interpretation.
- A product is selected.
- A manufacturer instruction changes.
- A standard is verified.
- A source moves from research file to manuscript.
- A chapter adds a new Code block.

If a source affects a build decision, record it.

**Professional**

The index should be maintained like a project control document. A stale source index is dangerous because it looks authoritative while pointing to old assumptions.

During final production, decide whether the reader-facing version includes only source families, full citations, or a separated references section.

**Code**

Before permit submission and before construction, recheck the current official sources for the project jurisdiction and permit date.

The final authority is the current adopted code path, approved plans, product listings, manufacturer instructions, and authority having jurisdiction.
